隐私政策

生效与最近更新日期：2026 年 11 月 16 日

这份政策说明 TokenLens 桌面应用、tokenlens.online 官方云服务及本说明网站如何处理信息。核心是：用尽量少的资料完成用量统计和多设备同步，不把你的代码或对话内容当作统计数据。

一句话说明

只在本机使用时，不上传你的工具用量；连接官方云服务时，上传的是 Token 数字和必要的统计信息，不是提示词、回答、代码或文件内容。

1. 适用范围

本政策适用于：

  • Windows 和 macOS 上的 TokenLens 桌面应用；
  • 由 TokenLens 项目提供的 tokenlens.online 官方同步与账号服务；
  • TokenLens 官方介绍及本政策页面。

本政策不适用于 GitHub、Google、邮件服务、网络服务商、你使用的 AI 编程工具，或其他第三方自行提供的服务。它们会依据自己的隐私政策处理信息，相关链接见本政策第 5 节。

自行搭建的服务器由搭建者管理。选择「自己的服务器」时，数据处理由该服务器的配置和运营方决定，请向其索取相应说明。不要把自建服务器的管理凭据交给 TokenLens 项目。

2. 本机采集与云端上传

2.1 只在本机使用

下载并打开应用后，可以直接查看本机用量，无需注册账号或连接服务器。应用读取本机受支持的 AI 编程工具日志，把统计结果保存在本机数据库中。

在只使用本机功能时，应用不会把这些工具用量上传到 TokenLens 云服务。关闭窗口不会停止后台采集；彻底退出应用后停止采集，下次启动会按保留在本机的日志补记。

2.2 连接服务器时处理的信息

只有你主动添加并连接服务器后，应用才会把以下统计信息同步到所选服务器，用于多设备汇总：

用量数字输入、输出、缓存读取、缓存写入、推理 Token 数，以及工具提供的费用、Qoder credits、消息数和轮次标记等。
统计标签工具与模型名称、计费渠道与处理档位、时间、会话标识、数据精度、估算汇率版本和必要的去重标识。
设备与同步状态你填写或自动生成的设备名称、操作系统与设备性质、应用及采集版本、扫描和上传状态、最近心跳等。

当前采集实现不会生成或上传项目目录的哈希或项目标签。若以后增加可选项目统计，会同时更新应用说明和本政策，不会用项目名称代替完整路径上传。

上传凭据分为只写和只读两种，存放在 macOS 钥匙串或 Windows 凭据管理器中；服务器只保存其哈希。账号会话与设备同步凭据分开，页面中的网页脚本不能读取这些凭据。

2.3 不会作为用量上传的内容

  • 提示词、AI 回答、代码或文件内容；
  • 完整或绝对的文件路径；
  • 会话标题；
  • 用于证明电脑身份的序列号、硬件 UUID 或主机名。

设备性质可以标为笔记本或台式机；应用随机生成设备绑定请求号，用来避免重复登记，它不是硬件追踪标识。

3. 账号与第三方登录

只有使用官方云服务的账号登录等功能时，才需要账号。第一次登录会创建独立空间，之后登录回到同一空间。一个已验证邮箱对应一个账号；使用相同已验证邮箱的不同登录方式可能关联到同一账号，不会另外创建空间。

3.1 使用 Google 继续

TokenLens 请求 Google 的基本身份权限（openid、email、profile），用于取得：

  • Google 账号的内部身份标识（sub），用于识别你的账号；
  • Google 已验证的邮箱，用于创建或关联 TokenLens 账号；
  • 你提供的昵称和头像地址，用于在应用侧栏展示账号资料。

这些信息仅用于登录、创建或找回对应空间、防止重复账号及展示账号资料。TokenLens 不请求 Gmail、Google Drive、日历、通讯录等权限，也不会把这些基本资料出售或用于广告画像。

登录时由服务器完成网页授权。Google 访问令牌只在换取资料时使用一次，不写入数据库；TokenLens 不保存你的 Google 密码或长期 Google 授权令牌。客户端密钥只保存在服务器，不进入桌面应用。

3.2 使用 GitHub 继续

GitHub 登录取得 GitHub 用户 ID、已验证邮箱、显示名称和头像地址，用途与上述账号功能相同。TokenLens 不要求访问你的仓库、代码或组织内容。

3.3 使用邮箱验证码

邮箱登录会处理你的邮箱地址，并保存一次性验证码的哈希、有效期、尝试次数和发送限制信息。验证码通过邮件服务商发送；没有配置邮件服务的自建服务器不能使用此方式，不会假装邮件已经发送。

3.4 登录状态

服务器保存账号会话的哈希、创建时间、有效期和撤销状态。当前会话最长有效 30 天，过期或撤销后需要重新登录；同一账号最多保留 10 个有效会话。Google 和 GitHub 不取得你的 TokenLens 会话或设备同步凭据。

4. 信息如何使用

TokenLens 将上述信息用于：

  • 计算和展示 Token 构成、趋势、会话、设备及缓存命中率；
  • 按公开价格表估算 API 等价成本，并标注 Qoder 等估算来源；
  • 创建和识别账号空间、隔离不同空间的数据、管理设备与同步；
  • 保持上传与读取安全、发现失败和长期离线、恢复备份及排查故障。

成本是根据公开价格表计算的估算值，不是账单；价格表更新后，保存的历史事件可能重新估算。TokenLens 不会用你的代码或对话训练模型，因为它不采集这些内容。

5. 服务提供方与信息分享

TokenLens 不出售个人信息，也不为了广告目的向第三方分享你的 Token 用量。为提供你主动选择的功能，以下服务会按其实际角色处理必要信息：

云服务器与网络服务商托管数据库、备份与 HTTPS 连接；像多数网络服务一样，可能处理连接所需的 IP 地址、时间和基本请求日志。
Google / GitHub你主动选择对应登录方式时，处理登录授权及基本账号资料。
邮件服务商你选择邮箱验证码时，接收邮箱地址以投递验证码；当前默认接口为 Resend，自建服务可以另行配置。
公开价格与更新服务应用或服务器下载公开价格表；应用按设置先检查 GitHub Release，失败时尝试 TokenLens 官网的发布副本。官网也从 GitHub 的正式发布同步并校验安装包。这些是匿名请求，不带账号会话、设备同步凭据或你的用量。

相关第三方政策：

  • Google 隐私政策；
  • GitHub 隐私声明；
  • Resend 隐私政策。

除非为提供上述服务、遵守适用法律或保护服务与用户安全所必需，TokenLens 不会向其他人提供你的账号或云端用量。使用这些跨境或境外服务时，信息可能在你所在国家或地区以外处理。

6. 保存、安全与删除

6.1 保存期限

  • 本机数据保存在你的电脑中，直到你删除应用数据、移除本机设备或自行清理；应用的采集设置和日志保留期会影响可见历史。
  • 云端用量与设备记录在提供服务所需期间保留，用于跨设备历史统计和备份恢复。
  • 账号及第三方身份资料在账号存续期间保留；第三方资料可能在再次登录时更新。
  • 邮箱验证码10 分钟有效，使用一次后失效；服务器只保存其哈希及防滥用状态。
  • 账号会话最长 30 天；进行中的 Google 授权流程只存于服务器内存，10 分钟后过期。

官方服务按计划制作备份，用于故障恢复。当前在线备份保留 30 天；因恢复演练或异地副本产生的其他备份，可能按相应存储位置另行保留。被删除的信息可能在这些副本自然轮换前继续存在，不会被用于日常看板。

6.2 断开、退出与删除并不相同

退出账号只撤销当前登录状态，不会停止本机采集，也不会删除云端历史。断开服务器会移除本机保存的云端连接凭据和待上传队列，但保留本机数据库、设备与服务器上的历史。

移除本机设备可让它不再计入本机看板并暂停采集；重新开始后，应用可能重新扫描仍在的工具日志，历史用量可能重现。这不等同于彻底删除电脑上的原始日志或服务器记录。

目前应用内没有「一键删除账号及全部云端历史」入口。需要删除官方云服务的账号、空间或历史时，请通过第 10 节的公开渠道联系我们，并说明要处理的账号与范围。为防止误删他人数据，我们可能需要通过该账号的已验证邮箱确认请求。

6.3 安全措施

凭据只保存在系统钥匙串或服务器端，服务器保存其哈希；同步走 HTTPS，网页脚本不取得设备凭据，不同空间的数据相互隔离。上传字段有明确白名单，服务端会拒绝未知字段。任何网络和本机存储都不能保证绝对安全，请同时保护你的电脑、服务器和第三方账号。

7. 本说明网站

TokenLens 首页和隐私政策是静态公开页面，不提供网页版看板，不设置登录表单，不使用分析、广告或营销追踪脚本，也不加载第三方字体或图片。

这些页面本身不设置 Cookie，也不主动收集表单信息。托管与网络服务商仍可能为连接安全和故障排查处理基本访问日志，如 IP 地址、请求时间、请求路径和浏览器信息。你可以在应用的「设置」中关闭自动更新检查；手动检查和打开下载链接仍由你主动发起。

8. 你的选择与权利

  • 不连接服务器，直接只在本机使用；
  • 在设置中暂停或恢复采集、管理开机启动和自动更新检查；
  • 管理或移除设备、断开服务器、退出账号；
  • 通过 Google 或 GitHub 的账号设置撤销对 TokenLens 的授权。撤销后，未来不能再用该授权完成登录；已经保存的 TokenLens 账号资料和历史不会因此自动删除。

视你所在地适用法律，你可能有权请求访问、更正、导出或删除个人信息，或限制特定处理。可通过第 10 节提出请求；本机数据由你直接控制，第三方账号资料也可以通过对应第三方管理。

9. 未成年人

TokenLens 是面向开发者和编程工具用户的用量统计工具，不面向儿童，也不会故意收集儿童个人信息。如果你认为未成年人向我们提供了不适当的个人信息，请通过下述渠道联系我们处理。

10. 政策更新与联系

如果采集字段、第三方服务或数据用途发生变化，我们会同步更新本页面并修改顶部日期；重大变化会在项目发布说明中说明。请在新功能启用前阅读更新后的政策。
