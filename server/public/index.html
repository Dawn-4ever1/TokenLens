01 / 构成

每一种 Token，各就各位

输入、输出、缓存读取、缓存写入与推理分开呈现。缓存命中率单独计算，不把缓存读取直接当作实际扣费。

02 / 趋势

看见变化，也找到变化

按小时、日、周或月查看趋势，对比本周与上周、本月与上月。日历和使用习惯热力图，让高峰与节奏一目了然。

03 / 会话

从一次会话，看到每一轮

按标题、项目或模型搜索，查看各轮 Token 构成与耗时。子代理归入父会话，不让细节淹没在总数里。

04 / 筛选

只看此刻关心的部分

按日期、设备、工具、模型和项目组合筛选。点一下工具或某一天，就能带着这个范围进入对应会话。

阅读完整隐私政策
01

只在本机使用，也可以完整统计

不连接服务器时，工具用量不会上传到 TokenLens 云服务。你可以随时暂停采集，或选择断开服务器。

02

同步不包含对话和代码内容

云端只接收 Token 数字与必要的统计标签。提示词、回答、代码、文件内容和完整路径不上传；工具明确保存的会话标题与项目名用于展示和筛选。

03

每个账号空间，彼此独立

设备凭据保存在 macOS 钥匙串或 Windows 凭据管理器。云端按账号空间隔离数据，不让其他账号看到你的设备和用量。

04

官网也不做访客画像

官网没有第三方分析脚本、Cookie 或第三方字体与图片。服务器只按天累计页面打开和下载次数，不保存 IP、浏览器标识或访客标识。

下载后一定要注册或登录吗？

不需要。本机版直接打开即可使用完整的本地用量分析。只有想使用官方云服务、把多台电脑放进同一空间时，才需要登录账号。

支持哪些电脑和 AI 编程工具？

目前提供 Windows 10 / 11（64 位）与 macOS 11+（Apple 芯片 M 系列）正式安装包；Intel 芯片的老款 Mac 可从 GitHub 开源仓库自行构建。应用自动发现本机支持的 Claude Code、Codex、Qoder 国际版 / CN、Gemini CLI、OpenCode、OpenClaw、DeepSeek Harness、ZCode 等工具；具体范围以当前版本说明为准。

首次打开遇到系统安全提示怎么办？

当前为 0.x 开源早期版本，暂未购买商业代码签名证书。Mac 首次打开若提示「无法验证开发者」或「已损坏」，可先拖入「应用程序」，在「系统设置 → 隐私与安全性」底部点「仍要打开」，或在终端执行 xattr -cr /Applications/TokenLens.app 后再打开；Windows 若出现 SmartScreen 蓝屏提示，点「更多信息」→「仍要运行」即可。安装包均由 GitHub Actions 公开构建并附带 SHA-256 校验值。

Token 总量就是实际扣费吗？

不是。总量包含缓存读取等构成，不能直接当作实际扣费。成本根据公开价格表计算，是 API 等价估算，不是订阅或中转服务账单；Qoder 的 credits 与折算口径也会单独保留。

可以只在自己的电脑上保存吗？

可以。不连接服务器时，用量统计保存在本机。连接云端后，本机仍继续记录；网络不可用不影响本地查看。退出账号或断开服务器不等于删除云端历史，具体边界请阅读隐私政策。

多台电脑如何放在一起看？

每台电脑都安装 TokenLens，选择官方云服务并登录同一个 GitHub、Google 或邮箱账号。不同电脑随即进入同一空间，无需逐台复制配对码。也可以在应用中选择自己的服务器。

可以在手机或浏览器里查看用量吗？

目前看板是 Mac 与 Windows 桌面应用。这个官网提供产品介绍、下载与隐私政策，不是网页版看板，也不会在网页里显示你的真实用量。
