你的日志，你的数据

先在本机运行，
需要时再同步。

TokenLens 是常驻桌面应用，后台按需读取本机工具日志，窗口关闭也能继续记录。它不是网页版看板，也不需要把代码交给云端。

  • 只采集数字和必要的统计标签提示词、回答、代码、文件内容、绝对路径和会话标题不上传。
  • 本机与云端各自独立保存断开服务器仍保留本机历史和采集；退出账号不等于删除云端记录。
  • 公开价格，仅供估算成本按公开价格表计算，是 API 等价估算，不是订阅或中转服务的账单。
